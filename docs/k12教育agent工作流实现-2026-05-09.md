# K12 教育 Agent 工作流实现说明 - 2026-05-09

## 修改概述

本次将项目原有示例工作流从：

```text
planner -> executor -> reviewer
```

改造为面向 K12 教育系统的通用 Agent 工作流：

```text
用户请求
-> 意图识别 Agent
-> 路由到对应业务 Agent
-> 安全合规 Agent
-> 输出结果
```

初期实现 5 个基础 Agent：

1. `TeachingDesignAgent`：教学设计 Agent
2. `HomeworkAgent`：作业与练习生成 Agent
3. `StudentTutorAgent`：学生答疑 Agent
4. `LearningAnalyticsAgent`：学情分析 Agent
5. `SafetyGuardAgent`：内容安全与合规 Agent

## 主要改动

### 1. 统一工作流状态模型

修改文件：

- `src/state.py`

新增 `WorkflowState` 作为 LangGraph 主状态契约，并扩展 K12 教育场景字段：

- `user_role`
- `grade`
- `subject`
- `topic`
- `intent`
- `intent_confidence`
- `missing_fields`
- `requires_clarification`
- `clarification_question`
- `selected_agent`
- `agent_output`
- `safety_status`
- `safety_notes`
- `final_output`

同时新增 `merge_dicts`，用于合并 `results` 和 `metadata`，避免后续节点覆盖前序节点结果。

### 2. 改造 LangGraph 工作流

修改文件：

- `src/graph.py`

新工作流拓扑：

```text
START
-> intent_classifier
-> teaching_design | homework | student_tutor | learning_analytics
-> safety_guard
-> finalize_output
-> END
```

其中：

- `intent_classifier` 负责识别用户意图
- `route_by_intent` 根据意图选择业务节点
- 业务节点生成对应教育场景结果
- `safety_guard` 做内容安全与合规检查
- `finalize_output` 生成最终用户可见输出

### 3. 新增 Agent 基础结构

新增文件：

- `src/agents/base_agent.py`
- `src/agents/agent_registry.py`
- `src/agents/teaching_design_agent.py`
- `src/agents/homework_agent.py`
- `src/agents/student_tutor_agent.py`
- `src/agents/learning_analytics_agent.py`
- `src/agents/safety_guard_agent.py`

各 Agent 均基于 `BaseEducationAgent`，返回统一的 `AgentResult`。

### 4. 新增工作流节点

新增文件：

- `src/nodes/intent_classifier.py`
- `src/nodes/router.py`
- `src/nodes/teaching_design_node.py`
- `src/nodes/homework_node.py`
- `src/nodes/student_tutor_node.py`
- `src/nodes/learning_analytics_node.py`
- `src/nodes/safety_guard_node.py`
- `src/nodes/finalize_output_node.py`

节点职责：

| 节点 | 说明 |
| --- | --- |
| `intent_classifier_node` | 通过规则优先的方式识别教育意图，并预留 LLM 分类扩展点 |
| `route_by_intent` | 根据 `intent` 路由到对应业务节点 |
| `teaching_design_node` | 调用 `TeachingDesignAgent` 生成教学设计 |
| `homework_node` | 调用 `HomeworkAgent` 生成作业练习 |
| `student_tutor_node` | 调用 `StudentTutorAgent` 生成启发式答疑 |
| `learning_analytics_node` | 调用 `LearningAnalyticsAgent` 生成学情分析 |
| `safety_guard_node` | 调用 `SafetyGuardAgent` 执行安全合规检查 |
| `finalize_output_node` | 根据用户角色格式化最终输出 |

### 5. 更新运行示例

修改文件：

- `main.py`

新增 4 个示例场景：

1. 教师备课
2. 作业生成
3. 学生答疑
4. 学情分析

运行命令：

```bash
uv run python main.py
```

### 6. 新增 LLM 封装占位

新增文件：

- `src/llm.py`

当前实现以规则分类为主，`src/llm.py` 预留后续接入 LangChain / OpenAI 的统一封装入口，避免业务节点直接硬编码模型调用。
